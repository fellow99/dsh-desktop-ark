## 1. 模块概述
**目的**：把"添加工作区"的目录选择对话框，从只能浏览应用沙箱，扩展为可在四个已授权主目录（沙箱 / 桌面 / 文档 / 下载）内浏览、下钻、新建并选中文件夹，同时保证四个目录互不越界。

**问题**：
- 上游默认的目录选择以进程家目录为起点；壳把家目录指向沙箱后，用户无法把桌面/文档/下载中的文件夹注册为工作区。
- 上游的自动装配方式会动态挂载客户端面，无法被静态替换；若不禁用，替换会与官方实现争抢同一插槽。
- 上游后端原语是全文件系统范围、无根限制；直接暴露给用户等于把整盘目录作为可选工作区。
- 用户目录可能未授权或不存在；静默回退会让用户以为"选的是桌面，实际是沙箱"。

**范围**：
- 范围内：四个主目录的解析与不可用状态、主目录切换、Miller 列浏览、面包屑截断、新建文件夹、选择与取消、授权门、主目录记忆、根围栏语义、与上游采纳链路的衔接。
- 范围外：工作区创建后的文件写入与权限语义（后续模块）、命令执行与沙箱策略（`105`）、通知（后续）、诊断端点（`107`）、用户目录 ACL 的申请材料（`108`）。

**状态**：本模块**全部为 planned**——插件包、客户端面、宿主侧根解析与授权门、两个插槽的注册都不存在。任何验收结论在实现前 MUST 记为未通过。

## 2. 用户故事
- 作为用户，我希望在选择工作区时切换到桌面/文档/下载，把已授权目录中的文件夹注册为工作区。
- 作为用户，我希望进入子文件夹后仍能回到该主目录的根，而不是被带到整个文件系统的根。
- 作为用户，当某个主目录尚未授权时，我希望在对话框内直接完成授权并继续，不必先去系统设置再回来。
- 作为用户，我希望下次打开对话框时停在最近使用的主目录（而不是上次进入的子目录），避免重复切换。
- 作为用户，当某个主目录不存在时，我希望看到"不可用 + 重试"，而不是被悄悄换到另一个目录。
- 作为维护者，我希望对话框没有任何提交任意绝对路径的入口，越界只可能是缺陷而不可能是用法。

## 3. 功能需求
### 3.1 主目录
- **FR-106-001**：对话框 MUST 在顶部渲染四个主目录标签：沙箱、桌面、文档、下载；顺序 MUST 固定为"沙箱 → 桌面 → 文档 → 下载"。
- **FR-106-002**：主目录标签 MUST NOT 因未授权或不存在而隐藏或删除；不可用时 MUST 只让内容区呈现不可用状态。
- **FR-106-003**：沙箱主目录 MUST 解析为应用文件目录下的工作区子目录；每次打开对话框 MUST 检查其存在性，不存在 MUST 自动创建（递归创建）。
- **FR-106-004**：桌面 / 文档 / 下载主目录 MUST 以固定绝对路径解析，MUST NOT 通过家目录猜测。
- **FR-106-005**：三个用户主目录 MUST 在打开或切换时做存在性检查；不存在或不可读时 MUST 显示原因与重试入口，MUST NOT 回退到其它主目录。
- **FR-106-006**：路径来源 MUST 为单一事实源；同一路径 SHOULD NOT 在多个层各自硬编码（例如界面层、插件配置、宿主常量三处各写一遍）。

### 3.2 浏览（Miller 列）
- **FR-106-007**：浏览视图 MUST 为多列（Miller）形态：未选中文件夹时单列全宽；选中文件夹后向右展开其子级新列。
- **FR-106-008**：每列 MUST 只列目录，不列普通文件；条目 MUST 按名称排序。
- **FR-106-009**：隐藏条目 MUST NOT 被渲染；界面 MUST NOT 提供"显示隐藏文件"开关。
- **FR-106-010**：面包屑 MUST 截断到当前主目录根；最高可点击层级 MUST 为该根；根之上的层级 MUST NOT 渲染。
- **FR-106-011**：界面 MUST NOT 存在任何手动路径输入入口（含路径编辑、粘贴路径、命令行式跳转）。
- **FR-106-012**：切换主目录 MUST 重置浏览栈到该主目录根，并清空当前选中项。
- **FR-106-013**：下钻 MUST 只接受由当前列条目产生的子路径；MUST NOT 接受外部构造的路径。
- **FR-106-014**：单列条目数超过后端上限时 MUST 展示"结果被截断"的提示；MUST NOT 静默少列。

### 3.3 新建文件夹
- **FR-106-015**：对话框 MUST 提供"新建文件夹"入口，输入限定为单个目录段名称；后端校验失败 MUST 在输入处提示。
- **FR-106-016**：名称输入 MUST 有默认值；与同级已有目录重名时 MUST 自动追加序号（2、3…）直至不冲突。
- **FR-106-017**：创建成功后 MUST 重新列目录并选中新目录；创建失败 MUST 留在输入态并显示原因。

### 3.4 选择与采纳
- **FR-106-018**：确认时 MUST 采纳当前选中文件夹；无选中项时 MUST 采纳当前列所在目录。
- **FR-106-019**：采纳 MUST 通过既有的工作区创建链路回传绝对路径，MUST NOT 改变既有采纳语义。
- **FR-106-020**：取消或关闭对话框 MUST 视为正常取消，MUST NOT 产生错误提示。

### 3.5 授权门
- **FR-106-021**：列目录返回权限类错误（拒绝访问 / 操作不允许）时，MUST 先做权限预检；已授权 MUST 视为瞬时错误并直接重试一次。
- **FR-106-022**：未授权时 MUST 在对话框内部发起系统授权申请，期间按钮 MUST 进入忙碌态并禁止其它操作。
- **FR-106-023**：授权成功 MUST 自动重试列目录；授权失败或被拒 MUST 展示原因并提供"打开应用信息"入口与手动重试，MUST NOT 静默失败。
- **FR-106-024**：授权 MUST 由用户操作触发（打开对话框或切换主目录），MUST NOT 在冷启动时批量弹窗。
- **FR-106-025**：授权流程 MUST NOT 改变对话框之外的应用状态。

### 3.6 记忆与围栏
- **FR-106-026**：主目录选择 MUST 持久化在客户端本地存储，键 MUST 属于该插件的私有命名空间。
- **FR-106-027**：记忆 MUST 只保存主目录 id，MUST NOT 保存子路径；再次打开 MUST 停在该主目录根。
- **FR-106-028**：存储值非法（不属于四个 id）MUST 回退为沙箱主目录。
- **FR-106-029**：根围栏 MUST 由三件事共同保证：首列锁定主目录根、面包屑截断、无手动路径输入；切换主目录是唯一换根方式。
- **FR-106-030**：本模块 MUST 复用上游后端的列目录/建目录原语，MUST NOT 自实现文件系统访问。
- **FR-106-031**：本模块 MUST 以单包双面形态提供（宿主面 + 客户端面），并独占上游两个工作区目录流插槽；自动装配行 MUST 处于禁用状态。
- **FR-106-032**：浏览类失败 MUST 在对话框内消化；只有采纳阶段的失败 MAY 进入上游错误链路。

## 5. 验收场景
> **声明面变更（2026-10-20 R2 → 2026-10-21 R4 已回滚）**：R2 曾把 `READ_WRITE_{DOCUMENTS,DOWNLOAD}_DIRECTORY`
> 从 `module.json5` 移除；**R4 起重新声明**（并新增 `CUSTOM_SCREEN_CAPTURE` 等，见 `docs/ACL配置.md` §1）。
> ⇒ 「文档/下载」两根**恢复可授权**：点 Tab 只查状态，点「请求权限」会弹系统授权框，授予后自动列目录。
> 沙箱根行为不变。

### AC-106-01 四个主目录可见且可切换
- **Given** 应用已启动并打开"添加工作区"对话框
- **When** 依次点击四个主目录标签
- **Then** 每个标签下的内容区切换到对应主目录根，浏览栈被重置（对应用例 TC-106-001、203 的 AC-1）

### AC-106-02 沙箱根自动重建
- **Given** 沙箱工作区目录被删除
- **When** 打开对话框并停留在沙箱标签
- **Then** 目录被自动重建并可正常列出（TC-106-002）

### AC-106-03 用户目录缺失不回退
- **Given** 桌面目录不存在或不可读
- **When** 切换到桌面标签
- **Then** 内容区显示不可用说明与重试入口；MUST NOT 显示沙箱或其它目录内容（TC-106-003）

### AC-106-04 根围栏不可上溯
- **Given** 用户在文档主目录下进入两级子目录
- **When** 连续点击面包屑最左侧可点击项
- **Then** 停在文档主目录根，没有更上一层；界面不存在路径输入框（TC-106-004、TC-106-005）

### AC-106-05 未授权时对话框内完成授权
- **Given** 应用尚未获得文档目录权限
- **When** 切换到文档标签
- **Then** 对话框内弹出系统授权窗口；同意后自动列出目录，拒绝后显示原因与"打开应用信息"入口且可重试（TC-106-006）

### AC-106-06 只记忆主目录
- **Given** 用户上次在下载主目录下进入了子目录
- **When** 关闭并重新打开对话框
- **Then** 停在下载主目录根，不回放子路径；若记忆值非法则停在沙箱（TC-106-007）

### AC-106-07 选中结果被采纳
- **Given** 用户在桌面主目录选中某个文件夹
- **When** 点击"打开"
- **Then** 回传绝对路径，工作区创建成功；创建失败时出现可重试的错误提示（TC-106-008）

### AC-106-08 新建文件夹
- **Given** 当前列已有名为"未命名文件夹"的目录
- **When** 使用默认名称新建
- **Then** 新目录名为"未命名文件夹 2"，创建后自动选中；重名冲突不覆盖既有目录

## 6. 非功能需求
| 类别 | 要求 |
|---|---|
| 安全 | 根围栏为安全属性：任何"能提交任意绝对路径"的路径都是缺陷，不得以"高级用法"保留 |
| 安全 | 界面 MUST NOT 泄露授权凭据；日志 MUST NOT 打印用户目录的完整内容清单 |
| 性能 | 单列列目录请求在千条量级 MUST 在 1 s 内呈现；MUST NOT 在打开对话框时预遍历用户目录 |
| 稳定性 | 授权被拒、目录被删除、后端不可用均 MUST 表现为可重试的对话框内状态，不得导致应用或宿主崩溃 |
| 一致性 | 同一路径只允许一个事实源；界面、插件配置、宿主常量 MUST 保持一致 |
| 兼容 | 上游插槽名或 owner 契约变化时 MUST 以启动期断言失败暴露，不得静默不注册 |

## 7. 假设与约束
- 上游两个工作区目录流插槽是单占位（single slot），owner 契约包含 open / busy / 选中回传 / 取消回传 / 错误回传五项；替换点存在且无需改上游前端。
- 上游后端原语（列目录 / 建目录）在全文件系统范围内可用，且由自动装配行动态挂载；因此必须先禁用该行再静态挂载原语行。
- 三个用户主目录的路径为固定绝对路径，其可读写性取决于系统授权；授权是运行期事实，不能由构建期假设替代。
- 桌面目录属受限权限（需 ACL），文档/下载在首次访问时弹窗；ACL 是否进入发布剖面由 `108` 负责。
- 本模块只支持选择目录，不支持文件选择与多选。
