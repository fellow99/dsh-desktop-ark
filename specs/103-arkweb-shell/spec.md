# 103 ArkWeb 外壳 —— 模块规格（spec）

> 模块：`103-arkweb-shell`｜状态：**部分 implemented（导航围栏、错误覆盖、文件选择、深色 4 项 planned）**｜最后更新：2026-10-18
> 对应 spec：本文件；实现方案见 `specs/103-arkweb-shell/plan.md`

## 1. 模块概述

**目的**：用系统 Web 容器承载上游 dsh 的 Web 前端，提供窗口、启动覆盖层与最小必要的容器策略；不重写界面、不注入 preload、不参与鉴权。

**要解决的问题**

| # | 问题 | 本模块的回答 |
|---|---|---|
| P1 | 冷启动到服务就绪之间是空窗，容易出现白屏 | 首帧加载本地启动页，启动/失败状态以原生覆盖层叠加 |
| P2 | Web 前端需要本地存储与站点数据库，否则首屏崩溃 | 显式开启脚本、DOM 存储、站点数据库；关闭本地文件访问 |
| P3 | 页面可能被导航到任意外部地址 | 导航必须限定在本机服务源（**planned**，as-built 未实现） |
| P4 | 启动页会污染返回栈 | 每次页面加载完成后清理历史 |

**范围内**：窗口内容装配、Web 容器配置、启动/错误覆盖层、页面生命周期回调、模块清单（设备形态/单实例/权限）。
**范围外**：服务实现、启动编排判定、宿主能力实现、上游前端代码、网络代理。

**现状（事实）**

| 能力 | 状态 |
|---|---|
| 单实例、2in1/tablet 限定、长时任务声明 | implemented |
| 本地启动页 + 启动/失败覆盖层（阶段、详情、复制、退出入口） | implemented |
| 脚本 / DOM 存储 / 站点数据库开启，本地文件访问关闭 | implemented |
| 加载完成清理历史 | implemented（每次页面加载后都清） |
| 导航围栏（仅放行本机服务源） | **planned**（无拦截回调） |
| 新窗口拒绝 / 外部链接交系统浏览器 | **planned** |
| 文件选择与下载交系统能力 | **planned** |
| 加载/HTTP 错误覆盖层 | **planned** |
| 深浅色跟随 | **planned**（启动页固定浅色） |
| 权限清单与实现一致 | **not-implemented**（14 项权限中 8 项暂无代码路径） |

## 2. 用户故事

- 作为用户，我打开应用立刻看到品牌启动页，而不是空白窗口或系统白屏。
- 作为用户，启动失败时我能看到阶段、原因与可复制详情，并知道需要退出后重开。
- 作为用户，我能正常使用上游界面的本地存储、登录态与站点数据库。
- 作为维护者，我不需要为壳维护任何业务界面，只需维护容器策略与生命周期。

## 3. 功能需求（RFC 2119）

### 3.1 窗口与页面

- **FR-103-001**：应用 MUST 单实例运行；重复启动 MUST 复用已有实例。
- **FR-103-002**：应用 MUST 只声明 2in1 与 tablet；MUST NOT 声明 phone。
- **FR-103-003**：主界面 MUST 渲染上游 Web 前端；MUST NOT 修改上游业务代码、MUST NOT 注入 preload。
- **FR-103-004**：首帧 MUST 是随包的本地启动页；MUST NOT 使用 `data:` 页面或空白文档。
- **FR-103-005**：页面 MUST 开启脚本执行、页面本地存储与站点数据库；MUST 关闭本地文件访问。
- **FR-103-006**：启动期间 MUST 叠加显示阶段与说明；失败 MUST 显示原因、可复制详情与退出/重启入口。
- **FR-103-007**：每次页面加载完成 MUST 清理历史，保证返回键不回到启动页。

### 3.2 导航与外部能力

- **FR-103-008**：页面导航 MUST 限定在本机服务源（含 `about:blank`）；非本机导航 MUST 被拦截（**planned**）。
- **FR-103-009**：外部 `https` 链接 MUST 交给系统浏览器/系统能力，MUST NOT 在壳内新开窗口（**planned**）。
- **FR-103-010**：文件选择与下载 MUST 走系统文件能力，MUST NOT 让页面直接访问本地文件（**planned**）。
- **FR-103-011**：页面加载失败或 HTTP 错误 MUST 呈现可读错误覆盖层（阶段、原因、重试入口），MUST NOT 白屏（**planned**）。
- **FR-103-012**：页面 MUST NOT 参与鉴权：不解析、不生成、不校验凭据；MUST 只透传入口地址（FR-RUN-005）。

### 3.3 生命周期与合规

- **FR-103-013**：收到系统终止回调时 MUST 放行终止（≤2 秒），MUST NOT 拦截或延迟。
- **FR-103-014**：外观 MUST 跟随系统深浅色；错误与阶段信息 MUST 以文本呈现（**planned**）。
- **FR-103-015**：模块声明的权限 MUST 与已实现能力一一对应；未实现能力 MUST NOT 提前声明（当前不满足）。
- **FR-103-016**：窗口 MUST 只加载唯一页面入口；MUST NOT 引入原生聊天界面或第二套导航栈。

## 4. 关键实体

### 4.1 外壳状态（View State）

| 字段 | 类型 | 说明 |
|---|---|---|
| `phase` | 字符串 | 来自启动快照的阶段名 |
| `statusText` | 字符串 | 面向用户的一句话状态 |
| `detail` | 字符串 | 失败详情，可复制 |
| `showOverlay` | 布尔 | 是否显示覆盖层；入口地址到达后关闭 |
| `attached` | 布尔 | 容器控制器是否已挂载 |
| `pendingUrl` | 字符串 | 待加载的入口地址（含一次性凭据） |

### 4.2 启动页文档（BootDocument）

随包的静态 HTML：品牌标题、脉冲动画、固定提示文案；无脚本、无网络请求、无凭据。

### 4.3 模块清单（ModuleManifest）

设备形态仅 2in1 与 tablet；实例模式为单实例；后台模式为长时任务；原生库压缩打包并在安装时解压；权限清单为 14 项申请 + 2 项定义。

### 4.4 窗口阶段（WindowStage）

只加载唯一页面入口；无 `pages` 之外的二级页面；窗口关闭语义交给系统。

## 5. 验收场景

### TC-103-001 首屏经启动页进入前端
- **Given** 服务已就绪　**When** 打开应用
- **Then** 先显示本地启动页，随后加载出自报入口地址的 SPA；**证据**：截图

### TC-103-002 本地存储可用
- **Given** 前端已加载　**When** 页面脚本读取本地存储
- **Then** 结果不为 null，首屏不崩；**证据**：页面 JS 断言 + 截图

### TC-103-003 返回键不卡在启动页
- **Given** 前端已加载　**When** 触发返回
- **Then** 不回到启动页；**证据**：操作序列截图

### TC-103-004 非本机导航被拦截
- **Given** 页面尝试导航到外部地址　**When** 拦截生效
- **Then** 页面保持在本机服务源；**证据**：拦截日志（**blocked**：as-built 无拦截）

### TC-103-005 外部链接交系统浏览器
- **Given** 用户点击 `https` 外链　**When** 系统浏览器被拉起
- **Then** 应用内不出现新窗口；**证据**：系统浏览器截图（**blocked**：能力面只支持 https，但页面未接线）

### TC-103-006 加载失败显示错误覆盖层
- **Given** 服务不可达　**When** 页面加载失败
- **Then** 显示可读错误与重试入口，不白屏；**证据**：截图（**blocked**：as-built 只覆盖启动阶段失败）

### TC-103-007 权限清单与实现一致
- **Given** 模块清单　**When** 逐项比对代码引用
- **Then** 每个已声明权限都有代码路径或明确的使用场景；**证据**：清单比对（当前 8 项无代码路径）

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 首屏 | 启动页 MUST 在窗口内容加载后立即呈现（同步渲染，无网络依赖） |
| 稳定性 | 页面加载失败 MUST NOT 使应用退出；覆盖层可继续退出或等待重试 |
| 内存 | 单窗口单容器实例；清理历史不得重建容器 |
| 安全 | 关闭本地文件访问；不注入脚本；不参与鉴权 |
| 可访问性 | 关键状态与错误 MUST 有文本，不只靠颜色/动画 |
| 外观 | 跟随系统深浅色（planned） |

## 7. 假设与约束

- **系统 Web 容器**：ArkWeb 随系统提供 Chromium；本模块不打包渲染引擎。
- **回环访问**：页面加载 `http://127.0.0.1:<port>/` 依赖门禁 G1；未通过则整条路线不成立。
- **鉴权在服务端**：一次性凭据只通过入口地址传递一次，之后由容器自身管理 cookie。
- **启动页是无脚本静态页**：覆盖层由原生侧渲染，启动页不参与状态显示。
- **单页应用**：窗口只加载一个页面入口；不引入多页面路由。
- **状态标注**：导航围栏、新窗口、文件选择/下载、错误覆盖层、深色均为 `planned`；权限一致性为 `not-implemented`。

## 8. 依赖

| 依赖 | 性质 | 影响 |
|---|---|---|
| 系统 ArkWeb / ArkUI 窗口 | 平台 | 容器能力、生命周期、覆盖层渲染 |
| 模块 101 启动快照 | 同工程 | 阶段、状态文本、失败详情、入口地址 |
| 模块 102 载荷 | 同工程 | 提供可加载的上游 Web 前端 |
| 模块 104 宿主能力桥 | 同工程 | 外部打开（`https`）与后续文件选择 |
| 上游 Web 前端 | 内容 | 自带主题、存储与路由，不自建替代界面 |
| 门禁 G1 | 验收前置 | 容器能否访问回环服务 |

- **FR-103-017**：页面错误覆盖层 MUST 只在**主文档**（`request.isMainFrame()`）加载失败时显示；子资源失败 MUST 仅记录（`[DSH_DESKTOP_ARK] 子资源加载失败…`），不得遮挡已经可用界面。
